РАСПИСАНИЕ БАШГАУ — ОБНОВЛЕНИЕ 23.10.2026

УСТАНОВКА НА GITHUB PAGES
1. Распакуйте BashGAU_GitHub.zip.
2. Загрузите все файлы из архива с заменой в папку, опубликованную через GitHub Pages.
   ZIP загружать вместо файлов не нужно. Главная страница — index.html.
3. sw.js, manifest.webmanifest, icon.png и icon-192.png должны лежать рядом с index.html.
4. Для домена bgau-class.ru дождитесь успешной проверки DNS в Settings → Pages и включите Enforce HTTPS.
5. Откройте сайт с интернетом и дождитесь статуса «Офлайн готов». После этого расписание открывается без сети.
6. Кнопка установки появляется, когда браузер разрешил установку. Инструкции находятся в Меню → Офлайн-режим.
   На iPhone: Safari → Поделиться → На экран Домой. Поддержка офлайна зависит от браузера и сохранённого кэша.

ЧТО ИЗМЕНИЛОСЬ
— Поддержка снова доступна в шапке, боковом меню ПК и основном меню: Telegram @csenchis и MAX.
— Звёздочки закрепляют несколько групп. Быстрые кнопки закреплённых групп находятся над календарём.
— В выборе группы сначала показаны закреплённые и недавние группы, затем группы по курсам и формам обучения.
— Поиск группы понимает название, код, курс и форму обучения.
— Фильтр «1 подгр.» / «2 подгр.» оставляет выбранную подгруппу и общие пары. «Все» показывает обе.
— Кнопка закладки рядом с фильтром сохраняет подгруппу отдельно для каждой группы, включая «Все».
  Если изменить закреплённый фильтр, его сохранённое значение обновится.
— Все общие пары подписаны «Вся группа». Если исходная таблица не содержит деления, это указано под фильтром.
— Номера недель по-прежнему фильтруются по встроенным массивам недель, без расширения диапазонов.
— Более крупные карточки, яркие акценты, увеличенные подписи и кнопки на телефонах от 320 px.
— Меню → Экран и читаемость → Крупный увеличивает текст ещё на 15%.
— Меню закрывается свайпом вниз за верхнюю часть. Если содержимое прокручено, сначала вернитесь к его началу.
— Свайп влево/вправо по расписанию переключает дни. Свайп между краями недели переключает и неделю.
— Кнопка «Сегодня», количество пар точками, индикатор сегодняшнего дня и таймер текущей/следующей пары сохранены.
— Обновления: история реальных изменений относительно предыдущего открытия на этом устройстве.
— Новая версия проверяется при возвращении на страницу и каждые 5 минут, пока она открыта.
— При обнаружении новой версии появляется предложение обновить страницу.
— По желанию можно включить системное уведомление о найденных изменениях.

ГРАНИЦЫ УВЕДОМЛЕНИЙ
Изменения обнаруживаются при открытии обновлённого сайта. После первой установки сравнивать пока не с чем;
история появится после следующего реального обновления расписания. Перенос показан как старое и новое время.
Постоянная фоновая доставка при полностью закрытом приложении не подключена.
Изменения исходных Excel сами по себе не попадают на сайт: необходимо обновить опубликованный комплект.

СОХРАНЕНО
