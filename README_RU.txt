РАСПИСАНИЕ БАШГАУ — ДЛЯ GITHUB PAGES

1. Распакуйте архив и загрузите все файлы в одну папку, которую публикует GitHub Pages.
   Главная страница должна называться index.html.
2. Не пропускайте sw.js и manifest.webmanifest: они нужны для офлайн-режима опубликованного сайта.
3. Откройте сайт с интернетом и дождитесь отметки «Офлайн готов». После этого проверьте открытие без сети.
4. Собственная иконка: замените icon.png (PNG, 512×512 пикселей).
   Уменьшенную копию той же картинки сохраните как icon-192.png (192×192).
   Обе иконки должны находиться рядом с index.html. Заглушки уже включены в архив.
5. Меню → Офлайн-режим: инструкции для Android и iPhone, а также скачивание отдельного HTML.

Расписание встроено в HTML. Сохранённый файл index.html можно открыть отдельно без интернета;
для работы опубликованного сайта без сети загружайте весь комплект.
