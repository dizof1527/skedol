УСТАНОВКА НА GITHUB PAGES
1. Распакуйте BashGAU_GitHub.zip.
2. Загрузите все файлы из архива с заменой в папку, опубликованную через GitHub Pages.
   ZIP загружать вместо файлов не нужно. Главная страница — index.html.
3. sw.js, manifest.webmanifest, icon.png и icon-192.png должны лежать рядом с index.html.
4. Для домена bgau-class.ru дождитесь успешной проверки DNS в Settings → Pages и включите Enforce HTTPS.
5. Откройте сайт с интернетом и дождитесь статуса «Офлайн готов». После этого расписание открывается без сети.
6. Кнопка установки появляется, когда браузер разрешил установку. Инструкции находятся в Меню → Офлайн-режим.
   На iPhone: Safari → Поделиться → На экран Домой. Поддержка офлайна зависит от браузера и сохранённого кэша.
