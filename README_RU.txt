КАК ОБНОВИТЬ САЙТ НА GITHUB

1. Распакуйте BashGAU_v7.zip.
2. Загрузите файлы из архива с заменой в ту папку репозитория, из которой работает GitHub Pages.
   Главная страница уже называется index.html. Сам ZIP вместо файлов загружать не нужно.
3. Рядом с index.html должны остаться sw.js, manifest.webmanifest, icon.png и icon-192.png.
4. CNAME содержит существующий домен bgau-class.ru. В этом обновлении настройки домена не менялись.
5. После публикации откройте сайт с интернетом и дождитесь статуса «Офлайн готов».
   Версию можно посмотреть в Меню → Актуальность расписания: 2026-10-27.1.
6. Если ранее установленное приложение показывает прежнюю версию, закройте его и снова откройте с интернетом.
   При предложении обновить страницу нажмите соответствующую кнопку.

Отдельный файл index_BashGAU_v7.html предназначен для просмотра и скачивания.
При загрузке именно этого файла на GitHub переименуйте его в index.html.
Для полноценного офлайн-приложения используйте комплект из архива.
